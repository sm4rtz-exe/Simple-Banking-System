# Simple-Banking-System

## Overview
My first simple baking system, which utilizes JSON for account management.

## Motivation
Built this project to practice Python programming and work with JSON files.

## Features
- User login
- View current balance
- Deposit and withdraw money
- Change password
- Save user data to JSON

## What I Learned
Working with a JSON file, since I used to store data inside a Python file, which is insecure. So I decided to try using JSON.

## Challenges
The major challenge of this project is that I don't know how to load the JSON file into Python, but after I successfully load the JSON, everything is quite similar to Python dictionaries and lists.
